# HTML 提取算子

通用、纯计算的 HTML 字符串处理插件。HTML 必须由 Workflow 上游节点提供；插件不联网、不访问浏览器页面环境。

## 方法

- `html.extract`：按选择器提取文本或属性。
- `html.links`：提取链接地址，默认选择器为 `a[href]`。

支持的选择器子集：标签、`#id`、`.class`、`[attr]`、`[attr=value]`，以及空格分隔的后代选择器。它不是完整浏览器 CSS 引擎，不支持伪类、兄弟选择器或布局计算。

## 安全与边界

- 输入是普通字符串，输出是 JSON 字符串或数组。
- 无网络、DOM、时钟、存储或其它宿主 API。
- 不执行脚本，不解析页面运行时状态。
- 适合把不同站点的页面结构提取成后续 JSON/集合算子可处理的数据。
