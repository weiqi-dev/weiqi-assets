📥 扩展资源下载入口（插件 / 工具）

插件与 LLM 工具声明走这个清单，先取清单再按条目路径取资源：

https://weiqi-dev.github.io/weiqi-assets/registry.json
GET /registry.json
 → 过滤 type / pointId / id（只装 plugin）
 → GET <entry.path>
 → 插件：GET <manifest.code> 取源码，构造 PluginArtifact
 → 工具：仅展示 definition，不注册执行器
 → 校验：PluginValidator + QuickJS 试跑 + validateRankingOutput
 → 写入工件（enabled=false，人工启用）

所有路径都是仓库内相对路径，以 registry.baseUrl 为基准拼接。 默认源只读、由 git 发布；宿主可另加自定义源。下载 ≠ 安装 ≠ 启用；失败一律回落宿主内置实现。

🧠 技能配方入口（独立清单）

技能配方是另一套清单，不经过上面的 registry.json。宿主单独取这个地址：

https://weiqi-dev.github.io/weiqi-assets/skills/registry.json
GET /skills/registry.json
 → 解析纯声明配方（schemaVersion / id / version / triggers / primitives / prompt）
 → 配方只引用宿主已注册的原语名，不含任何可执行代码
 → 用户在「🧠 技能」→「在线技能」点安装，写进本地技能库
 → 只有本地库里启用的条目才会被 LLM 调用（装了才生效）
 → 引用宿主没有的原语 → 只展示、不可安装

结构契约在 weiqi-bot 的 application/skill/SkillRecipe.ts / SkillTypes.ts； 本仓库没有对应 schema，scripts/validate.mjs 也不校验这份清单。 默认源是宿主代码常量，用户可在面板改成任意 https 源或一键恢复（内容未经官方审核时需自担信任）。 当前 4 条配方见下方「技能配方列表」。

📦 资源列表

plugin总分排序
plugins/ranking/total-score/plugin.json
扩展点 ranking / spec v1 / 入口 rank({matches}) → {columns,rows}。 按总得分（积分与对手分合成）排名，同分依次比较积分、直胜、对手分顺减；可在赛事详情页选用。
plugin直胜排序
plugins/ranking/direct-win/plugin.json
扩展点 ranking / spec v1 / 入口 rank({matches}) → {columns,rows}。 积分→对手分→直胜→逆减，展示直胜列；对应赛事详情页原先内置的「直胜」口径，现在由插件提供。
plugin简易排序
plugins/ranking/simple/plugin.json
扩展点 ranking / spec v1 / 入口 rank({matches}) → {columns,rows}。 积分→对手分→逆减，不展示累进分；对应赛事详情页原先内置的「简易」口径，现在由插件提供。
plugin公历转农历 llm-tool.lunar
plugins/llm-tool/lunar/plugin.json
扩展点 llm-tool / spec v1 / 入口 call({method,args})。 把公历单日或日期范围换算成农历（含闰月），模型在对话里通过 llm_tool_call 调用； 装好启用后零网络。含 exposes[] 方法白名单与 smoke[] 安装自检。
toolweb_fetch 工具声明
tools/web-fetch/v1/tool.json
对齐 ModelToolDefinition 的声明镜像；执行器由 weiqi-bot 内置， 本仓库不提供可执行代码，在线平台只展示、不安装。

🧩 技能配方列表（纯声明 · 装了才生效）

skill图片对阵表导入赛事 event.import-pairing-image · v1
触发「对阵表 / 导入比赛 …」，引用 event_parse_draft + event_commit_draft。 把图片对阵表整理成可编辑表格，用户确认后宿主再写库。
skill做题练习 puzzle.tsumego · v4
触发「死活题 / 做一道 / 手筋 / 官子 …」，引用 navigate_to。 每轮按题型 / 难度重算；链接由宿主渲染成按钮，模型正文里不写任何网址。
skill查天气 weather.wttr · v1
触发「查天气 / 天气怎么样 / 今天天气」，引用 web_fetch。 取 wttr.in 的公开 JSON 归纳中文播报；取不到如实说明、不编造数据。
skill查股价 stock.quote · v2
触发「查股价 / 查股票 / 股票价格 …」，引用 web_fetch。 取腾讯公开行情文本归纳中文报价播报；仅供参考，取不到不编造价格。

配方都是纯 JSON、只组合宿主原语；新增 / 修订配方改 skills/registry.json 即可， 无需重建 Web 资源包。与插件「默认停用、人工启用」不同，技能安装即启用（纯声明零代码）。
